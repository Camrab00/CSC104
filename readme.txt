Project Title:
Gaming Universe Hub

Description:
The Gaming Universe Hub is a three-page website dedicated to gaming fans who want to explore featured games, learn about game details, and contact the site creator. The website showcases modern design with a dark gamer-style theme, specialty fonts, and multimedia content. It includes a home page with featured games, a games page with a data table and embedded video, and a contact page with a message form and email link.

============================================================
List of Files
============================================================
1. index.html – Home Page
   • Introduces the website and its purpose.
   • Displays three featured games: Hades 2, Battlefield 6, and Terraria.
   • Includes navigation menu, images, and text for each featured game.

2. games.html – Games Page
   • Lists featured games in a table (Game, Genre, Release Year).
   • Includes an embedded YouTube trailer (multimedia requirement).
   • Uses consistent navigation and design.

3. contact.html – Contact Page
   • Provides a user-friendly form for visitors to send a message.
   • Includes an email hyperlink: superhulk61@gmail.com
   • Maintains consistent design and layout.

4. style.css – External Stylesheet
   • Controls layout, colors, and typography for all pages.
   • Implements a consistent color scheme, hover effects, and grid layout.
   • Uses Google Font “Orbitron” for a futuristic gaming style.

5. images/ – Image Folder
   • hades2.jpg
   • battlefield6.jpg
   • terraria.jpg
   (Images are used in the featured section on the home page.)
